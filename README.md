# Claude Web Builder 🚀
*A modular, multi-template prompting framework to build high-end, custom websites using a free Claude account.*

**A Note from the Creator:**
Hey, I'm Damilola Ayodele ([@damiboi](https://github.com/damiboi)). I built this because I kept seeing people get frustrated when free AI tools timed out, or worse, generated generic, ugly websites that looked like they were made by a robot. I wanted to give anyone—regardless of their coding skills—a tool that acts like a patient, high-end web architect. I hope this helps you build something you're genuinely proud of.

---

## What is this?
Building websites with AI on a free tier often leads to broken code or hitting message limits. This repository provides a complete system—custom instructions, design guardrails, layout components, and archetype selection—that turns Claude into a disciplined **Conversational Web Architect**. 

Instead of guessing, Claude guides you through choosing a website archetype, designing a blueprint, and writing clean, modern HTML/CSS code section-by-section.

---

## How to Use This Framework

### Step 1: Fork this Repository
Click the **Fork** button in the top-right corner of this page to copy this repository to your own GitHub account.

### Step 2: Set Up a Claude Project
1. Open [Claude](https://claude.ai).
2. Go to **Projects** on the left-hand sidebar and click **Create Project**. Name it *Web Builder*.
3. Open your project's **Custom Instructions** and paste the entire contents of `project-instructions.md`.
4. Upload all files inside the `knowledge/` folder into your Project's **Knowledge** section.

### Step 3: Start Building
1. Open a new chat inside your new Claude Project.
2. Type: **"Let's build my website."**
3. Claude will greet you, present the archetype choices, and guide you step-by-step!
