# How to Resume Building in a New Chat (After Reaching Limits)

If you hit a message limit or start a fresh chat, paste this prompt along with your current code:

> "I am continuing work on my website project. Here is the current `index.html` code we built previously:
>
> ```html
> [PASTE YOUR HTML CODE HERE]
> ```
>
> Please review this code. Reply with 'Code received. What modifications or additions would you like to make next?'"
