# Saving Your Website Code

1. In Claude's chat window, look at the code preview (Artifact) on the right-hand side.
2. Click the **Copy** or **Download** button at the top of the artifact window.
3. Open a simple text editor (like Notepad on Windows or TextEdit on Mac).
4. Paste the code and save the file with the exact name: `index.html`.
5. Double-click `index.html` to open and preview it directly in your web browser.
