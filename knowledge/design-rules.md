# Design and Aesthetic Guardrails

1. **Colors:** Stick to 2–3 restrained colors maximum (e.g., a dominant dark or light neutral, one accent color). Avoid random multi-color gradients.
2. **Typography:** Use clean, highly readable Google Fonts (e.g., Inter, Plus Jakarta Sans, Playfair Display). Keep font weights clear (headings bold, body regular).
3. **Spacing:** Use generous padding (`padding: 4rem 0`) around sections. Avoid cramped, crowded layouts.
4. **Motion:** Restrict animations to soft fade-ins on scroll or smooth button lifts on hover. No jarring transitions.
5. **Images:** Never use broken Unsplash links or invented stock images. Use clean, branded colored placeholder boxes with clear text labels (e.g., "Hero Image Placeholder").
6. **Forms & Functionality:** Build contact forms using clean inputs with placeholder actions (`action="https://api.web3forms.com/submit"`) and a hidden access key field.
