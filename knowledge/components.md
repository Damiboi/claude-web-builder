# Archetype Component Snippets

## 1. Local Business & Hospitality (Restaurant / Cafe)
- **Menu:** Filterable menu tab system above a CSS Grid layout of menu items.
- **Booking:** Reservation form grid containing Date, Time, Number of Guests.

## 2. Tech Startup & SaaS
- **Pricing:** Monthly / Annual toggle switch with side-by-side cards.
- **FAQ:** Clean, collapsible accordion using `<details>` and `<summary>`.

## 3. Professional Consultant & Agency
- **Case Studies:** Clean card grid featuring Client Name, Challenge, and Key Outcome Stat.

## 4. Creative & Personal Portfolio
- **Gallery:** Lightbox image grid.

## 5. The Witty 404 Error Page
If the user requests a "Page Not Found", use a full-height flexbox container with a funny headline related to their archetype (e.g., Restaurant: "Looks like this page got eaten.") and a "Return Home" button.

## 6. The "Human Element" (Optional Founder's Story)
If the user shared their personal story/name during the introduction, include a dedicated "About" or "Meet the Creator" section. Write the placeholder text to reflect their personal details. If they did not share personal details, keep it strictly professional or skip it.
